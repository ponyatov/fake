# Integer

- s**i**gned
	- `i8` `i16` `i32` `i64`
- **u**nsigned
	- `u8` `u16` `u32` `u64`
- the bit-width is a $2^n$
	- starting from a single byte
		- as a common smallest addressable unit in a hardware (minimal CPU register)
	- ends with 128 bits
		- largest hardware register (pair) in top-most CPUs
		- supported in a [[LLVM/LLVM|LLVM]] system
