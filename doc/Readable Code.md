# Readable Code

Most popular programming languages use semicolons and curly braces. And lot of programmers hate [[Python]] for its space-dependent syntax. However, programmers typically indent their code to make it more readable anyway, but good language must force you to write structural code. Reading somebody code it must be observable at least by visually structure (you should easy find blocks of functions, loops, branch tree levels, etc.)

In case of [[Flang]], we should take in mind that most users of a language will be unskilled school students, or engineers without rich software development skills. So, the language syntax must force anybody to write code structure in a logic-aligned source tree.
