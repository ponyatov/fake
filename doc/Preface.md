# Preface

This a specification for still non-existent programming language for embedded systems development I want to have every day on my workspace in place of classical C/C++, modern Rust, or ugly JS.

For my sorrow I have no any compiler developer skills to make it real by myself, but maybe some crazy team of CS students will be interested to implement it, or at least somebody skilled will consult me how to do it from a scratch.

Anyway, here it's a dream of programming language for microcontroller firmware and embedded Linux development for making IoT and control systems, designed from a view of a hobby-level developer. I want to take some great ideas from some non-popular languages looks like must have features in a control software language.
